# MazeSolution - 迷宮生成與路徑規劃專題 Final Report


## 專題簡介

這是一個互動式迷宮求解系統，能夠自動生成隨機迷宮，並透過三種不同的演算法來尋找最短路徑或最佳路徑。使用者可以觀察不同演算法在相同迷宮中的表現差異，比較它們的路徑選擇、執行時間和成本效益。

## 主要功能

- **隨機迷宮生成**：產生具有分岔與死路的高複雜度迷宮
- **多種地形系統**：
  - 普通道路（移動成本 1）
  - 草地（移動成本 3）
  - 池塘（移動成本 5）
  - 牆壁（不可通行）
- **三種求解演算法**：
  - DFS（深度優先搜尋）- 使用堆疊
  - BFS（廣度優先搜尋）- 使用隊列
  - Dijkstra（最短時間成本演算法）- 考慮地形成本 使用優先隊列
- **視覺化呈現**：彩色輸出顯示路徑與地形
- **效能分析**：顯示各演算法的路徑長度、時間成本與執行時間

## 使用說明

1. 執行程式後輸入迷宮大小（奇數，建議 51~151）
2. 觀看生成的迷宮地圖
3. 依序觀看三種演算法的求解過程與結果
4. 比較不同演算法的路徑選擇差異

## 環境需求

- C++17 或更高版本
- 支援 ANSI 色彩碼的終端機（Linux / macOS / Windows Terminal）

## 專題特色

- 模組化的地形設計，易於擴充新的地形類型
- 演算法獨立實作，可自由替換或新增
- 視覺化呈現，直觀理解路徑規劃過程

## 專題目的

本專題旨在探討不同路徑規劃演算法在網格地圖上的應用與比較，並透過視覺化的方式展示：

1. 演算法特性：觀察 BFS 的無權最短路徑、DFS 的深度優先探索，以及 Dijkstra 的加權最佳路徑
2. 成本考量：不同地形帶來的移動成本差異如何影響最終路徑選擇
3. 效能比較：分析三種演算法的時間花費與實際執行效率
